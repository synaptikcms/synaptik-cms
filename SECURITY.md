## Security Policy

### Reporting a Vulnerability

Please report security vulnerabilities to **[contact@synaptikcms.com](mailto:contact@synaptikcms.com)**.

Include as much detail as possible: affected version, steps to reproduce, and potential impact. We will acknowledge receipt within 48 hours and aim to release a patch as soon as possible.

Other bugs and issues can be reported at [https://github.com/synaptikcms/synaptik-cms/issues](https://github.com/synaptikcms/synaptik-cms/issues).
