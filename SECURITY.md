## Security Policy

### Reporting Vulnerability

Please report any security vulnerabilities to **[contact@synaptikcms.com](mailto:contact@synaptikcms.com)**.

Any other issue or bug can be reported at [https://github.com/synaptikcms/synaptik-cms/issues](https://github.com/synaptikcms/synaptik-cms/issues).

If we can confirm the issue, we will release a patch as soon as possible.
